# 两周开发计划总览

## 项目目标
开发一个基于浏览器的纯前端多周期 RISC-V CPU 模拟与可视化教学工具

## 团队分工

### 你（CPU 专家）- 70% 工作量
- **核心职责**：引擎层开发
- **关键模块**：汇编器、CPU 核心、控制单元、视图映射
- **优势**：有 CS61C proj3 经验，熟悉流水线和多周期 CPU

### 队友（Vibe Coding 专家）- 30% 工作量
- **核心职责**：UI 层开发
- **关键模块**：React 组件、SVG 渲染、动画、状态管理
- **优势**：精通前端开发，快速搭建 UI

## 协作接口

### 关键契约点

1. **类型定义**（Day 1）
   - 文件：`src/types/*.ts`
   - 这是你们的通信契约
   - 一旦确定，不要随意修改

2. **CycleSnapshot**（Day 8-9）
   - 你生成快照
   - 队友消费快照渲染 UI
   - 这是最重要的接口

3. **配置 JSON**（Day 2）
   - 队友创建配置
   - 你审查确认符合 CPU 逻辑

4. **Store Actions**（Day 10）
   - 队友定义接口
   - 你实现引擎方法

## 风险管理

### 高风险任务

   - 可能需要重构

3. **集成调试**（Day 11-12）
   - 可能出现意外问题
   - 预留缓冲时间

### 应对策略
- 如果某个任务超时，立即沟通
- 优先保证核心功能
- 次要功能可以延后
