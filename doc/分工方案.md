## 分工方案

### 你(有CS61C proj3经验)负责:

**核心引擎层开发(约70%工作量)**

1. **汇编器模块** (阶段2)
   - 词法/语法分析器
   - RV32I指令编码器
   - 反汇编器
   - 伪指令支持
2. **CPU核心模拟器** (阶段3 - 最关键)
   - ALU、解码器、立即数生成器
   - 存储器模块(指令+数据)
   - 寄存器堆
   - **多周期控制单元状态机**(这是核心,你的流水线经验在这里最有价值)
   - CPU主类集成
   - 快照生成逻辑
   - 执行历史管理
3. **视图映射层** (阶段4)
   - 将CPU状态快照转换为视觉属性
   - 动画序列编排
4. **单元测试**
   - 为所有引擎模块编写测试

### 你的队友(精通vibe coding)负责:

**UI层和项目搭建(约30%工作量)**

1. **项目脚手架** (阶段0)
   - Vite + React + TypeScript初始化
   - 依赖安装和配置
2. **类型定义** (阶段1)
   - 根据架构文档定义所有TypeScript接口
   - 创建数据通路配置JSON
3. **UI组件开发** (阶段5)
   - SVG数据通路组件(寄存器、ALU、MUX等)
   - 连线组件和动画
   - 代码编辑器(CodeMirror集成)
   - 控制面板(寄存器视图、内存视图、信号表)
   - 时间线和阶段指示器
4. **状态管理和集成** (阶段6)
   - Zustand store实现
   - 主应用布局
   - 键盘快捷键

## 协作接口

你们之间的协作点:

- **类型定义**(阶段1)是你们的契约 - 队友先定义,你基于类型开发引擎
- **CycleSnapshot接口**是核心桥梁 - 你生成快照,队友消费快照渲染UI
- 你完成引擎后,队友可以独立开发UI并用mock数据测试

## 为什么这样分工?

1. **发挥你的优势**: 多周期CPU控制逻辑、指令执行流程、数据通路设计是你熟悉的领域
2. **发挥队友优势**: vibe coding擅长快速搭建UI框架和组件,处理React生态
3. **并行开发**: 类型定义完成后,你们可以同时开发引擎和UI
4. **工作量**: 你承担约70%,符合你"多干一点"的要求
